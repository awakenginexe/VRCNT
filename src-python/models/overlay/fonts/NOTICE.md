# VRCNT Noto notices

VRCNT distributes the listed Noto font packs from Google Fonts under the SIL Open Font License 1.1 (OFL-1.1).
Every bundled pack contains its upstream `OFL.txt`; optional packs download the matching `OFL.txt` alongside the
verified font file before atomic cache activation.

## Exact source

- Repository: `https://github.com/google/fonts`
- Pinned revision: `2796410152d4f9524b68ed46e69c1b60f8e0f7c3`
- Raw immutable source prefix: `https://raw.githubusercontent.com/google/fonts/2796410152d4f9524b68ed46e69c1b60f8e0f7c3/`
- Manifest/version: `font-packs.v1.json`, `noto-gf-2796410152d4f9524b68ed46e69c1b60f8e0f7c3`

`font-packs.v1.json` records the family, source URL, revision, expected byte size, SHA-256 digest, copyright notice,
and OFL-1.1 provenance for every bundled and optional pack. It is the authoritative attribution index.
