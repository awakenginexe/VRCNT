# VRCNT 4.2.0 Transcription and Translation Reliability Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Prevent Whisper silence/music hallucinations from reaching translation providers, preserve one-cloud-attempt routing, and guarantee that an opted-in CTranslate2 fallback is warm and concurrency-safe.

**Architecture:** Treat accepted speech as the admission boundary for translation: live Whisper always uses acoustic VAD, and an empty or fully rejected decode returns `False` before the controller callback can create a trace. Keep the 4.1 per-message cloud assignment unchanged, centralize CTranslate2 readiness reconciliation in the controller, and protect mutable tokenizer work without serializing native inference.

**Tech Stack:** Python 3, `unittest`, faster-whisper 1.2.1/Silero VAD, CTranslate2 4.6.0, JavaScript package metadata, Tauri/Rust package metadata.

## Global Constraints

- Google + Bing routing is `M1 Google`, `M2 Bing`, `M3 Google`, `M4 Bing`.
- A message may attempt at most one public cloud provider.
- Cloud failure, timeout, or cooldown proceeds directly to CTranslate2 when Fallback is enabled.
- CTranslate2 performs no speculative translation while the cloud provider is pending.
- Translation off means CTranslate2 is unloaded.
- Cloud primary + Fallback on means CTranslate2 is loaded and idle until needed.
- Do not use phrase blacklists to suppress Whisper output.
- The cloud timeout remains exactly 5.0 seconds.
- Do not build an executable, installer, Tauri bundle, Python bundle, or release archive.
- Every production change starts with a focused failing test.

## File Structure

- `src-python/models/transcription/transcription_transcriber.py`: enforce live Whisper VAD and return no accepted result for acoustic/decoded non-speech.
- `src-python/config.py`: make live Whisper VAD an always-on, non-persisted safety default and expose version 4.2.0.
- `requirements.txt`: pin faster-whisper 1.2.1 for CPU installations.
- `requirements_cuda.txt`: pin faster-whisper 1.2.1 for CUDA installations.
- `src-python/tests/test_transcription_transcriber_pipeline.py`: cover silence, music-like non-speech, confidence rejection, VAD options, and privacy-safe metrics.
- `src-python/controller.py`: reconcile CTranslate2 residency for engine, tab, model, device, compute-type, fallback, and translation state transitions.
- `src-python/tests/test_main_function_activation.py`: cover the CTranslate2 readiness truth table and activation failures.
- `src-python/models/translation/translation_translator.py`: protect the shared tokenizer's mutable source-language state.
- `src-python/tests/test_translation_attempt.py`: reproduce mixed-language tokenizer races and verify load/unload safety.
- `src-python/tests/test_translation_scheduler.py`: retain the existing one-cloud-attempt, round-robin, cooldown, timeout, and parallel-queue contract tests.

def _refreshActiveCTranslate2Readiness(self, selection=None) -> None:
    if config.ENABLE_TRANSLATION is not True:
        return
    if selection is None:
        selection = config.SELECTED_TRANSLATION_ENGINES.get(
            config.SELECTED_TAB_NO,
            "",
        )
    providers = boundedTranslationProviderSnapshot(selection)

        bool(providers)
        and providers[0] != "CTranslate2"

    if needs_local:

class RacingTokenizer(FakeCTranslate2Tokenizer):
    def __init__(self):
        super().__init__()
        self.first_encode_entered = threading.Event()
        self.release_first_encode = threading.Event()
        self.encode_count = 0

    def encode(self, message):
        self.encode_count += 1
        if self.encode_count == 1:
            self.first_encode_entered.set()
            self.release_first_encode.wait(WAIT_SECONDS)
        return [self.src_lang, message]
