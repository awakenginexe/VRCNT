# VRCNT 4.2.1 Multilingual Conversation Profile Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Deliver VRCNT 4.2.1 with persistent one-to-three-language speaking and target profiles, one preferred received-translation language, engine-aware recognition, parallel Google candidates, restricted Whisper language selection, and the approved role-card UI.

**Architecture:** Keep the existing fixed three-slot configuration and progressive translation scheduler. Add one backend language-capability/policy module as the authority for saved-profile normalization and runtime activation. Extend the shared Whisper runtime lease so restricted detection and the single decode are serialized as one inference transaction. Make Google candidate recognition concurrent inside the existing phrase transcriber. Expose capability data to a reusable frontend profile utility and three explicit language role cards.

**Tech Stack:** Python 3.12, unittest, faster-whisper/CTranslate2, SpeechRecognition, React, Jotai-style application stores, SCSS modules, Node test runner, Tauri configuration files.
